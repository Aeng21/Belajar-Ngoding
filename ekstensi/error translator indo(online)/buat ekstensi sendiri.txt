Dengan ekstensi ini, sistem akan bekerja di latar belakang. Setiap kali compiler (seperti TypeScript) melemparkan error ke panel "Problems", ekstensi kamu akan menangkap teks tersebut, menerjemahkannya dengan cepat, dan menampilkannya kembali ke kamu.

Berikut adalah konsep cara kerja dan panduan teknis bagaimana kamu bisa membangun sistem tersebut:

1. Konsep Dasar Cara Kerja
Di dalam VS Code, semua error, warning, atau info yang muncul di panel "Problems" disebut sebagai Diagnostics. Sistem yang akan kamu buat memiliki alur seperti ini:

Mendengarkan (Listen): Ekstensimu akan memantau API VS Code untuk melihat apakah ada Diagnostic (error) baru di file yang sedang kamu buka.
Mengekstrak: Mengambil properti .message dari error tersebut (misal: "Cannot find name 's'.").
Menerjemahkan: Mengirim teks tersebut ke API penerjemah yang cepat (seperti Google Translate API, DeepL, atau API lokal ringan).
Menampilkan: Menampilkan hasil bahasa Indonesianya kepadamu. Cara paling nyaman adalah dengan menampilkan terjemahan saat kamu melakukan Hover (mengarahkan mouse ke garis merah error di kodemu).
2. Cara Membuatnya (Langkah-langkah Teknis)

Langkah 1: Inisialisasi Proyek Ekstensi

Langkah 3: Menulis Kode Ekstensi (di src/extension.ts)
Di file utama ekstensimu, kamu cukup menggunakan API HoverProvider milik VS Code. Sistem ini akan mengecek apakah kursor mouse-mu sedang menyorot sebuah error, lalu menerjemahkannya.

Berikut adalah gambaran kode intinya:

typescript
import * as vscode from 'vscode';
import translate from '@vitalets/google-translate-api'; // Package terjemahan
export function activate(context: vscode.ExtensionContext) {
    
    // Membuat fitur Hover (muncul saat mouse diarahkan ke kode)
    let hoverProvider = vscode.languages.registerHoverProvider('*', {
        async provideHover(document, position, token) {
            
            // 1. Ambil semua error (Diagnostics) di file ini
            const diagnostics = vscode.languages.getDiagnostics(document.uri);
            
            // 2. Cari apakah ada error tepat di posisi mouse saat ini
            const errorDiSini = diagnostics.find(d => d.range.contains(position));
            if (errorDiSini) {
                try {
                    // 3. Terjemahkan pesan error aslinya
                    const pesanInggris = errorDiSini.message;
                    const hasil = await translate(pesanInggris, { to: 'id' });
                    
                    // 4. Tampilkan ke dalam kotak melayang (Hover) menggunakan format Markdown
                    const tampilanMarkdown = new vscode.MarkdownString();
                    tampilanMarkdown.appendMarkdown(`🇮🇩 **Terjemahan Error:**\n\n_${hasil.text}_`);
                    
                    return new vscode.Hover(tampilanMarkdown);
                } catch (err) {
                    return null; // Abaikan jika gagal menerjemahkan
                }
            }
        }
    });
    // Daftarkan ekstensi ke memori VS Code
    context.subscriptions.push(hoverProvider);
}

Kenapa menggunakan Ekstensi VS Code?
Universal: Sekali diinstall, sistem ini akan jalan di semua proyek lamamu maupun proyek baru di masa depan tanpa perlu setup ulang package.json atau hal lainnya.
Bahasa Apa Saja: Sistem ini tidak peduli apakah itu error TypeScript, HTML, CSS, Python, atau PHP. Selama muncul di tab "Problems", sistem ini bisa menerjemahkannya.
Performa: Menerjemahkan hanya saat kamu menyorot (Hover) error, sehingga tidak membuat VS Code menjadi lambat (hemat memori).
